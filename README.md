# 📚 Student Study Planner

A lightweight web app that helps students organize their study tasks.

## Features
- Add study tasks with subject and deadline
- Mark tasks as completed
- See upcoming tasks sorted by deadline
- Tasks persist in browser via `localStorage`
- Clean, responsive UI

## Tech Stack
- HTML5
- CSS3 (Flexbox + Grid)
- Vanilla JavaScript

## How to Run
1. Download the folder.
2. Open `index.html` in any modern browser.
3. Start adding tasks!
